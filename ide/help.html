1. Platform Architecture & Overview

High-performance client-side browser evaluation suite with zero cloud dependency.

Browser Assessment IDE is an all-in-one assessment and examination platform engineered to run seamlessly directly inside any modern web browser. It combines a rich WYSIWYG document authoring studio, an online multi-language compiler for Python 3, C, and C++, an automated test runner, and a consent-driven proctoring engine.

🌐 100% Self-Contained & Portable

Every image, video, font, test case, and lock passcode is embedded directly as Base64 Data URLs inside single JSONs or complete ZIPs.

⚡ Cloud WebSocket Compilers

Connects via real-time WebSockets to compile and execute Python 3, C, and C++ programs with input/output sanitization.

🛡️ Privacy-First Evidence Proctoring

Captures continuous timestamped camera watermarks and full-session screen recordings without invasive automated AI guessing.

💾 Refresh & Crash Resilience

Active exam timers calculate absolute deadlines in LocalStorage. Browser refresh or accidental tab reload seamlessly resumes the timer.

3. Teacher & Examiner Guide: End-to-End Workflow

How to design, configure, protect, and distribute foolproof assessments.

1 Adding and Organizing Questions

Click the + Question button in the action row to create a new problem instance. You can navigate between questions using ‹ Previous, Next ›, or by clicking the Question Selector dropdown to reveal the visual All Questions Palette.

  • Every question receives a unique cryptographic Question ID (e.g. Q-M1K...).
  • Auto-Save: Changes to problem statements and code automatically persist to browser LocalStorage in real time.
  • Use the Delete button in the bottom right of the runbar to remove unwanted questions (minimum 1 question required).

2 Rich Problem Formatting, Media & Custom Fonts

Transform standard text into immersive, visually appealing problem statements using the top formatting toolbar.

🖼️ Embed Images & Animated GIFs

Click Image/GIF or press Ctrl+V with any copied clipboard screenshot. The image is instantly rendered and embedded.

🎥 Embed Video Clips

Click Video to embed MP4/WebM clips with built-in native player controls (play, pause, seek, volume).

🔤 Embed Custom Typography

Click Font to upload .woff, .woff2, .ttf, or .otf font files. The font is embedded into the question package and added to the font picker.

🗑️ Delete Selected Media

Click any image/video to highlight with a red border, then press Delete or right-click and choose Delete selected media.

3 Authoring Starter Code & Test Suites

Define the language, initial starter template, and input/output validation criteria for candidates.

  • Language Selector: Choose between Python 3, C, or C++. Starter templates update automatically.
  • Adding Test Cases: Click + Add Test in the Test Cases tab. Fill in the INPUT (what candidate code reads via stdin) and EXPECTED OUTPUT.
  • Testing the Solution: Click Compile and Test or press Ctrl+Enter to run all test cases and verify that your sample solution passes 100%.

4 Setting Up Exam Security & Teacher Locks

Prevent students from tampering with the problem statement, test cases, or exam timer.

🔒 Lock Problem Statement

Click 🔓 Lock Editing in the panel title. Enter a 4+ character passcode. The editor becomes read-only and formatting tools are disabled.

⏱️ Lock Assessment Timer

Set duration in minutes (e.g. 60), click 🔓 Lock Timer, and set a teacher passcode. Students cannot modify or reset the countdown.

🔒 Freeze Test Cases

Click 🔓 Freeze Test Cases in the runbar. Teacher test cases turn yellow and become read-only. Students can only add extra practice tests.

📧 Exam Setup (Proctoring)

Click Exam Setup in the top header. Enter the Examiner Email and Post-Exam Submission Window (e.g. 10 mins). This metadata is saved inside the exported ZIP.

4. Candidate & Student Guide: Taking an Assessment

Step-by-step instructions for test takers from import to final submission.

1 Importing the Assessment Package

Open the IDE in Google Chrome, Microsoft Edge, or Mozilla Firefox. You can import an assessment using any of these methods:

  • ⚡ Try with Mock Test Data: Click Try with mock test data in the welcome dialogue to immediately load a full 6-question programming assessment set (C, C++, Python 3) with pre-configured test cases without choosing any files.
  • 📄 Import JSON: Click Import JSON to load complete question sets (-all-questions.json) or single questions (.question.json) with embedded media, tests, and locks.
  • 📦 Import ZIP: Click Import ZIP to load an assessment package (.zip) provided by your instructor or examiner. Enter the student access password if prompted.

2 Identity Verification & Proctoring Consent

Before entering the exam, the Candidate Verification security gate appears:

Verification Gate
1. Enter Credentials

Type your Full Name and Roll Number / Student ID. The current date and exact start time are automatically captured from your device clock.

2. Camera Consent & Preview

Check the camera consent box and click Open Camera. Allow browser camera permissions and ensure your face is clearly visible in the preview box.

3. Screen Sharing Consent

Check the screen consent box and click Share Screen. Select Entire Screen or the browser window and confirm.

4. Ready to Exam

Once both previews are active and consents are checked, click the blue Ready to Exam button to begin.

⚠️
Proctored Environment Rules:
• Clipboard Disabled: Copying, cutting, and pasting (Ctrl+C / Ctrl+V) are blocked. You must write code directly.
• Right-Click Disabled: Context menus are restricted.
• Sequential Forward Navigation: You advance questions forward using Next ›. You cannot return to previous questions once submitted.
• Do Not Stop Screen Sharing: Stopping screen sharing will immediately conclude the exam and generate the submission package.

3 Solving Problems, Compiling & Evaluating

Write your solution in the code editor on the right:

  • Tab Indentation: Press Tab inside the editor for clean 4-space indentation.
  • Compile and Test (Ctrl+Enter): Runs your code against all test cases. The summary badge updates (e.g. All test cases passed or X of Y test cases passed).
  • Custom Input: Check Custom Input and click Run to test with your own custom manual inputs. Output appears in the Code Execution tab.
  • Font Scaling: Use A- and A+ to adjust code editor text size for optimal readability.
  • Full Screen (⛶): Toggle full-screen mode on either the problem statement or code editor for distraction-free focus.

4 Submitting the Exam & Sharing Results

When you finish all questions or when the timer reaches zero, the automated submission pipeline triggers:

1. Automated Package Generation

A progress modal shows ZIP, PDF, and media compilation progress from 0% to 100%.

2. Auto-Downloaded Files

Your browser downloads 4 files: [Roll]-[Name]-completed.zip, -completed.pdf, -camera-evidence.html, and -instruction.txt.

3. Email to Examiner

Follow the instructions on the screen and in instruction.txt. Email both the completed ZIP and PDF to the examiner within the configured submission window.

🎉
Browser Download Permission Note:
If your browser shows a popup asking "Allow site to download multiple files?", click Allow so all submission evidence files are saved successfully.

5. Proctoring, Security & Privacy Architecture

Transparent, ethical evidence recording designed for human review.

📸 Continuous 1 FPS Watermarked Frames

Captures 480x270 camera frames every second with millisecond timestamps and green checkmark authenticity patterns embedded permanently into the canvas.

🎥 Full HD Screen Recording

Records the candidate's shared exam screen and audio stream using the browser MediaRecorder API, saved into the ZIP as screen-recording/exam-screen.mp4.

Disables external clipboard injection, right-click inspection, drag-and-drop text insertion, and accidental page navigation.

7. Frequently Asked Questions & Troubleshooting

Quick answers to common questions and edge-case resolutions.

Q1: My camera or screen sharing permission fails to open. How do I fix it? ▼
Make sure you are accessing the application via a secure online connection (https://...). Modern web browsers require an active HTTPS connection to allow camera capture and screen sharing permissions. In your browser address bar, click the lock/tune icon next to the URL, set Camera and Screen sharing permissions to Allow, and refresh the page.
Q2: What happens if the student accidentally refreshes or closes the browser tab? ▼
The assessment state and timer deadline are saved in browser LocalStorage. Refreshing the browser resumes the exact remaining countdown without restarting the timer. Candidate details and current question progress are safely restored.
Q3: The browser only downloaded one file instead of all four submission files. What happened? ▼
Modern browsers often block multiple simultaneous downloads by default. Look for a notification icon in the right side of the browser URL bar (or download bar) that says "Multiple files were blocked". Click it and select Always allow multiple downloads from this site.
Q4: How do I completely clear all stored assessment data and start fresh? ▼
Click the Clear Cookies button in the top right header. This will stop active media recording streams, clear all assessment cookies, wipe LocalStorage/SessionStorage session keys, and reload a pristine starter workspace.
Q5: What programming languages are supported in the built-in compiler? ▼
The IDE natively supports Python 3, C (GCC), and C++ (G++). Code execution connects through real-time cloud WebSocket compilers with automatic prompt/echo stripping, stderr isolation, and syntax error diagnostics.
Q6: How can I try the IDE immediately with sample programming questions? ▼
When launching the IDE, click the ⚡ Try with mock test data button in the welcome dialogue. It will instantly import the built-in 6-question programming assessment set (covering C, C++, and Python 3 with automated test cases) so you can test and explore the IDE immediately without needing to upload any files.
