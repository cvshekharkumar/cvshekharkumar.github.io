Running on Online Server / HTTPS

How the online web deployment delivers fast, secure, and zero-setup assessment capabilities.

● Hosted on Online Web Server (HTTPS Supported)

Because this application runs directly on an online web server (over HTTPS or hosted domain), you gain immediate enterprise advantages with zero software downloads or terminal commands:

🔒

Native HTTPS Security

Webcam, microphone, and screen recording permissions work out-of-the-box via browser WebRTC APIs without running local Python servers.

⚡

Zero-Latency Client-Side Execution

All HTML/CSS/JS compilation, live sandbox rendering, ZIP packaging, and PDF generation execute 100% in the user's browser.

🌐

Universal URL Access

Examiners and students simply open the web URL in Google Chrome, Microsoft Edge, Firefox, or Safari on any computer.

🛡️

Network Fluctuation Proof

All code inputs, question states, and remaining timer values are continuously saved to browser LocalStorage. Network glitches won't erase work.

💡
Direct Web Link Access Teachers can simply send the website URL to candidates along with the assessment ZIP or JSON file. No developer tools or command lines required!

60-Second Quick Start

Get started immediately in two simple flows.

A

If you are a Teacher / Examiner

1. Open the app link in your browser.
2. Use + Question to write problem statements, embed images/GIFs/videos, and provide starter code.
3. Configure duration and click 🔓 Lock Timer and Exam Setup.
4. Click Export Set ZIP or Export JSON to download the exam file to distribute to candidates.

B

If you are a Candidate / Student

1. Open the app link in Google Chrome or Microsoft Edge on a Desktop/Laptop.
2. Click Import ZIP or Import JSON and select your test file.
3. Enter your Full Name and Roll Number, allow Camera & Screen Share permissions.
4. Code your solutions in HTML, CSS, and JS tabs, then click Finish Assessment to export your submission bundle.

🖥️
Desktop Display Recommendation For the optimal experience with side-by-side problem statements, multi-language code tabs, and live preview rendering, please use desktop or laptop computers (minimum 1080p recommended).

Examiner & Teacher Master Guide

Design challenging assessments, configure test locks, and export protected evaluation packages.

1

Create & Organize Questions

Click + Question to add new challenges. Click the question dropdown picker (e.g. Question 1 ▾) to view the visual question matrix palette. Reorganize, test, or delete questions with 1 click.

2

Write Rich Problem Statements

Use the full WYSIWYG problem editor to create professional instructions. Format headers, bold/italic styles, bulleted lists, code blocks, embed architecture diagrams, UI mockups, instructional GIFs, video guides, and custom typography.

3

Configure Exam Setup & Owner Email

Click Exam Setup in the top header. Enter the Owner Email (where candidate submissions should be emailed) and the Submission Window (e.g., 10 minutes grace period post-timer).

4

Lock Timer & Lock Problem Statements

Set the exam duration (e.g., 60 mins). Click 🔓 Lock Timer and set a 4+ digit passcode. Then click 🔓 Lock Editing on the problem statements. This ensures students cannot modify rules or bypass the timer.

5

Export Assessment Package (JSON or ZIP)

Click Export JSON for a single-file portable backup of all questions and media, or Export Set ZIP with optional exam password protection to distribute to candidates.

Teacher Passcode Locks & Security Architecture

Prevent tampering, restrict unauthorized tab navigation, and enforce academic honesty.

🔐

Auto-Locked Navigation & Setup

Upon importing an assessment ZIP for testing, navigation buttons (📖 Help Guide, 🏠 Home, 🛍️ App store) and Exam Setup are automatically locked. Clicking prompts "Enter password"—use 12345 to unlock.

⏱️

Passcode-Locked Timer

Prevents candidates from altering minutes or resetting the countdown. The timer starts strictly after student confirmation.

📝

Locked Problem Statement

Disables text editing, media deletion, and formatting toolbar. Candidates can read and fullscreen the statement without altering text.

🛡️

Safe Full Screen Resilience

Exiting full screen will not abort, terminate, or fail an active exam session. Candidates can toggle full screen freely (Fn + F11) without risk of losing progress.

🔑

SHA-256 Passcode Security

Teacher passcodes and lock hashes are salted and verified using browser-native Web Crypto SHA-256 so plain text is never exposed.

💾

Instant Pre-Refresh Autosave

Keystrokes are mirrored instantly to LocalStorage. Browser refresh or accidental tab switches trigger immediate state serialization.

Candidate & Student Online Exam Guide

Step-by-step instructions for verifying your identity, completing challenges, mobile navigation, and submitting.

1

Import Assessment File & Auto-Lock

Click Import ZIP or Import JSON and select your assessment file. If password-protected, enter the exam passcode. Upon import, top navigation links (📖 Help Guide, 🏠 Home, 🛍️ App store) and Exam Setup are auto-locked (passcode 12345) to maintain strict testing focus.

2

Candidate Verification & Consent

Fill in your Full Name and Roll Number. Read the academic integrity guidelines. Tick the camera and screen recording consent checkboxes.

3

Camera, Screen Sharing & Safe Full Screen

Click Open Camera and Share Screen (select entire screen). Once verified, click Ready to Exam. Toggle full screen with Full Screen IDE (Fn + F11). If you close or exit full screen, the exam will not terminate—you can safely refocus and continue coding.

4

Sequential Execution, Pre-Refresh Autosave & Mobile Floating Tools

Solve questions in order using HTML, CSS, and JS tabs. All code is autosaved on every stroke and flushed immediately before page refresh. On mobile devices:
• Top-Right Floating Timer: The capsule [ ⏱ MM:SS | Finish Assessment ] sticks to the screen header as you scroll down.
• Bottom-Right Floating Navigation: Tap the floating Next Question › button at the bottom-right to advance, which dynamically becomes Finish Assessment ✓ on the final challenge.

5

Finish Assessment & Export Submission Bundle

When done, click Finish Assessment (available in the bottom dock, top floating capsule, or bottom-right floating button), or let the countdown reach zero. The system bundles and downloads your verified {RollNumber}-{Name}-completed.zip, PDF report, screen recording, and camera evidence.

Online Server FAQ & Troubleshooting

Instant answers to common online deployment and examination questions.

Why are "📖 Help Guide", "🏠 Home", "🛍️ App store", and "Exam Setup" locked, and what is the password? ▼
After importing an assessment ZIP for testing, external navigation and administrative setup are automatically locked to prevent candidates from leaving the exam or altering configurations. When clicked, a modal prompts "Enter password". The default teacher unlock password is 12345.
What happens if a student exits full screen during the exam? ▼
The assessment will not terminate or submit. Candidates remain safely on their current question with their code intact, and can re-enter full screen at any moment using the Full Screen IDE (Fn + F11) button next to Lock Timer.
What happens if the candidate accidentally refreshes the browser? ▼
The application uses instant pre-refresh autosave (flushed automatically on beforeunload and pagehide) combined with UTC deadline storage. On reload, the assessment automatically restores the active question, all typed HTML/CSS/JS code, and continues the exact remaining countdown without losing progress.
How do mobile and tablet candidates view the timer and navigate questions? ▼
On mobile devices, a floating capsule at the top right displays [ ⏱ MM:SS | Finish Assessment ] permanently so candidates always see the timer while scrolling. Additionally, a floating button at the bottom right provides Next Question › to navigate smoothly, turning into Finish Assessment ✓ on the final question.
How do I try out the assessment IDE without creating questions from scratch? ▼
Click the Try with mock test data button on the welcome dialog (or click Import JSON and select SET-MUK5KO3I-all-questions.json). This instantly loads 7 complete front-end tasks with problem statements and pre-configured starter templates.
Why is camera or screen sharing not opening on the online server? ▼
Ensure you are accessing the website over HTTPS (e.g. https://...) or http://127.0.0.1. Modern browsers block webcam and screen access on insecure HTTP origins. Also, click the padlock/tune icon next to the URL in your address bar and ensure Camera and Screen Sharing permissions are set to Allow.
Does candidate work get lost if the internet disconnects during the exam? ▼
No! The application runs entirely inside the client's browser using LocalStorage and Web Workers. Even if the internet connection temporarily drops, the candidate can continue coding, previewing, and finishing the exam. Once finished, the ZIP and PDF download directly to their local disk without needing active server bandwidth.
What is the difference between Export Set ZIP and Export JSON? ▼
Export Set ZIP compiles a multi-file compressed exam bundle with optional candidate password protection designed for student distribution. Export JSON creates a single portable JSON file capturing all rich text, embedded media Data URLs, custom fonts, code, timer lock hashes, and owner settings for complete teacher backup and restore.
How do students send their completed test files to the examiner? ▼
When the assessment is finished (either manually or upon timeout), the browser automatically generates and downloads: {RollNumber}-{Name}-completed.zip, {RollNumber}-{Name}-completed.pdf, {RollNumber}-{Name}-camera-evidence.html, and {RollNumber}-{Name}-instruction.txt. Students email the completed ZIP and PDF files to the examiner email within the configured submission window.
How do I delete an embedded image or video from the problem statement? ▼
Simply click the image or video to select it (a highlight outline appears), then press Delete or Backspace on your keyboard. Alternatively, right-click the media item and choose Delete selected media.
How do I reset all exam data and clear saved local storage? ▼
Click the Clear Cookies button in the top header. This wipes all active session keys, cookies, and local storage, restoring the IDE to fresh teacher default mode.
