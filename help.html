🌐 2. Running on an Online Server

Important Ops Guide

When hosting Task Wall on an online server (e.g. GitHub Pages, AWS, Netlify, Vercel, or your corporate web server), keep these critical operational factors in mind:

⚠️
HTTPS is Required for Voice Input: Modern web browsers enforce strict security policies for hardware access. The SpeechRecognition and webkitSpeechRecognition voice dictation APIs will only function over secure HTTPS connections (or localhost for local development). Ensure your online server has an SSL/TLS certificate enabled!

🛡️ Browser Permission Lifecycle

When you tap the 🎤 Speak button for the first time on an online domain:

  1. Your browser displays a security prompt: "Allow [your-domain] to use your microphone?"
  2. Select "Allow while using the site" or "Always allow".
  3. A red pulsing indicator ● Listening… confirms speech recognition is active.
  4. Continuous listener automatically restarts between pauses and handles interim transcript streaming.

💾 Domain Storage & Isolation

How browser storage functions across online servers:

  • Origin Isolation: Each online domain (e.g. app.mycompany.com) maintains its own isolated localStorage database.
  • Cross-Tab Syncing: Changes made in one tab are saved instantaneously to the browser database.
  • Incognito Mode Warning: Private/Incognito browsing sessions wipe all storage when the window closes. Always take a JSON backup (Ctrl+S) if using shared or temporary kiosks.

⚡ 3. 60-Second Quickstart Workflow

Fast Track

Follow this rapid 4-step walkthrough to create, manage, and complete your first task.

1

Open the Add Drawer

Click the ➕ Add button in the left icon rail (or bottom navigation bar on mobile). The Add Drawer smoothly glides open and places focus into the task editor.

2

Dictate or Paste Your Task

Click 🎤 Speak to talk into your microphone, or paste an email snippet directly into the rich text box. Select the target date (defaults to today) and assign a priority level (High, Medium, or Low).

3

Attach Action Items, Sub-Steps & POCs

Type a clear action item (e.g. "Review architecture doc and reply by 4 PM"), add sub-checklists, and record the sender/recipient email details and assigned team members.

🔧 9. Troubleshooting & Diagnostics FAQ

Help & Answers

Solutions for common scenarios when using Task Wall on online servers:

Why does the Speak (Voice) button not work on my online server?
Web Speech API requires a secure HTTPS connection. If you are accessing your online server via http://, modern browsers (Chrome, Edge, Safari) disable microphone speech recognition for security. Ensure your server has SSL enabled (HTTPS). Also verify that you haven't blocked microphone permissions in your browser's URL bar settings.
Where are my tasks stored? Will anyone else on the online server see my data?
All tasks are stored strictly in your local web browser's localStorage sandbox. No data is sent to the server. Your data remains 100% private to your specific computer and browser profile. Other users visiting the same online URL will have their own independent, empty task wall.
How do I transfer my tasks from my office desktop to my laptop?
Press Ctrl+S or go to the 💾 Data panel and click Export all as JSON. Transfer that .json file to your laptop (via email, Slack, or USB), open Task Wall on the laptop, go to 💾 Data, and click Import from JSON. All your tickets will be merged seamlessly.
How do I print my tasks on standard A4 or Letter paper instead of A2 PDF?
In the filter bar, click the 🖨️ HTML export button. This downloads a clean standalone HTML document. Open it in your browser and press Ctrl+P. You can select any paper size (A4, Letter, Legal, A3) directly in your printer dialog!
Why does checking all sub-steps automatically mark the entire ticket Closed?
Task Wall features bidirectional checklist synchronization: when all sub-steps of a ticket are checked off, the master ticket status automatically switches to Closed (green stripe). If you untick any step, the master ticket returns to Open (amber stripe).
How does Task Wall adapt on smartphones and tablets?
Task Wall is fully responsive. On mobile screens, the left icon rail converts to a fixed, frosted-glass bottom navigation bar for effortless thumb reach. All creation and search panels slide up as responsive off-canvas drawers with backdrop tap-to-dismiss. You can also save Task Wall to your mobile home screen for an app-like full-screen experience.
