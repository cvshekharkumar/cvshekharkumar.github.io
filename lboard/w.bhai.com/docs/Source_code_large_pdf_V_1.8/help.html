Welcome to Lumenboard Studio

Lumenboard is a modern, privacy-first diagramming, digital whiteboard, and multi-page lesson creation suite. Designed for educators, software architects, visual thinkers, and presenters, it combines freehand pen tablet drawing, smart orthogonal connectors, rich text WYSIWYG editing, AI code/text visualizers, and full multi-format PDF/ZIP/DOCX imports and exports.

5-Minute Quickstart Guide

1

Place Your First Concept Box

Click the □ Concept button in the left tool rail (or choose a shape from the Design library). A styled card will appear at your cursor position. Double-click it to enter your title and explanation.

💡 Pro Tip: Use the icon short label field in the Inspector (e.g. API, DB, UI) or upload your own custom SVG/PNG icon.
2

Connect Nodes with Smart Orthogonal Connectors

Hold Shift and hover over any box edge to reveal the + handle. Click and drag towards another box to automatically establish an orthogonal connection with clean 90° bends and jump-over bridge bumps.

💡 Pro Tip: You can drag the circular bend handles along any line to customize the path geometry at will.
3

Annotate with Pen, Marker Highlighter, or Pencil

Select the ✒ Pen or ▰ Marker tool from the left rail. Choose your color and line thickness from the top canvas toolbar. Draw smoothly with full mouse or pen tablet (Wacom/Huion) pressure sensitivity.

💡 Tablet Protection: Stylus barrel buttons are protected against accidental context menus so your drawing flow is never interrupted.
4

Add Formatted Rich Text and Matrix Tables

Click the T (Write formatted text) tool and click anywhere on the canvas. Use the rich text toolbar to apply bold, italic, custom text & highlight colors, lists, or click ▦ Table to insert an interactive spreadsheet table.

5

Organize Lessons & Export Presentation

Use the bottom page bar to add new lessons (＋), drag to reorder slides, or color code tabs. When finished, click Export ↗ in the top right to generate a pristine Multi-Page PDF, SVG vector, High-Res PNG, or ZIP archive.

Smart Connectors & Flow Geometry

↳

Orthogonal Routing & Intersection Bridges

Lumenboard connectors automatically calculate optimal paths around obstacles:

  • Elbow Routing: Clean 90-degree orthogonal paths that keep architecture clean.
  • Intersection Jump Bridges: When two lines cross, Lumenboard renders an automatic semicircular bridge bump over the lower line so flows never get confused!
  • Styles: Straight, Line (no arrow), Both-side arrows (↔), Curved (Bézier), and Dashed lines.
⚡

Quick Connection Handles

Connect concepts at lightning speed without opening menus:

  • Shift + Drag: Hold Shift to reveal circular + handles on hovered card borders. Drag directly to another node to snap an arrow.
  • Custom Bend Points: Drag the center handle on any connector to bend it. Click Reset automatic route in the Inspector to restore the original path.

Import & Export Ecosystem

📥

Comprehensive File Import Support

Load content into Lumenboard using the File menu or direct Drag-and-Drop:

  • PDF Import (1 Page = 1 Lesson): Imports multi-page PDF documents and converts every page into a crisp, high-resolution lesson slide with a live progress indicator.
  • DOCX Lesson Packs: Import Microsoft Word files formatted with the provided Doc_to_diagram.docx template.

Multi-Format Export Center

Click Export ↗ in the top bar to output your work in any standard format:

  • Lesson-by-Lesson PDF: Generates a clean, multi-page document where Lesson 1 = Page 1, Lesson 2 = Page 2 with rendering progress.
  • Scalable Vector (SVG): Infinite-resolution vector graphics ideal for web publishing and slide decks.
  • High-Resolution PNG: Sharp raster export of the active canvas diagram.
  • Timestamped Lesson ZIP: Creates an organized ZIP archive containing individual JSON files named for each lesson.
  • Project JSON: Raw full project backup for local archiving and re-opening.

Frequently Asked Questions & Troubleshooting

Where is my diagram data stored? Is it secure? ▼
Your data is 100% private and stored locally in your browser's localStorage and IndexedDB (named lumenboard-media). No diagrams, code snippets, or uploaded images are sent to any remote servers unless you explicitly export them.
How do I import a 50-page PDF presentation? ▼
Go to File → Import PDF as lessons (or drag and drop the PDF file directly onto the canvas). Lumenboard will render each page as an individual crisp lesson card on its own slide tab, complete with a live page progress bar.
Why does a semi-circular bridge appear when arrows cross? ▼
This is Lumenboard's intelligent Connector Bump Bridge feature. When two orthogonal or straight connectors intersect, the upper connector automatically renders a clean jump-over bridge so viewers never mistake intersecting flows for unified branches.
How do I use my Wacom, Huion, or Apple Pencil tablet? ▼
Simply select the Pen, Pencil, or Marker tool. Lumenboard listens to native high-frequency Pointer Events with sub-pixel precision and suppresses stylus barrel button context menus to provide a smooth, paper-like writing experience.
How can I batch delete 200 unused pages from a large import? ▼
Open the Delete pages tab in the library sidebar. Use the 100-page quick range buttons (e.g. Select 101–200) or search with Inclusive/Exclusive modes, then click Delete selected pages. Lumenboard ensures at least one page is preserved.
