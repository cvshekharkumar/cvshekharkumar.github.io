5-Minute Quick Start Tour

From your first blank board to a complete, export-ready architecture diagram

Quick Path
1

Organize Lessons & Canvas Pages

In the top bar or rail, click + New Lesson to start a new page. Name your lesson, or assign an accent color tab (Mint, Sun, Coral, Purple) for rapid identification. Multiple lessons let you structure multi-chapter courses or complex microservice systems.

2

Drop Shapes, Cards, Frames & Rich Text

Click the Design Library icon on the left rail to explore pre-built architectural blocks (HTML, CSS, JS, DOM tree, Process steps). Alternatively, click Text or Card to drop customizable cards onto the canvas. Group related components inside Frames so they move together effortlessly.

3

Link Nodes with Auto-Routing Connectors

Hover over any card or shape to reveal the connection circle handle (or hold Shift and drag). Drop the line onto a target shape to create an anchored connector. Choose between Elbow (orthogonal auto-routing), Curved (smooth Bézier), or Straight styles. If two connectors cross, Lumenboard automatically renders an intelligent bridge bump!

4

Annotate with Pen, Pencil & Highlighter

Select the Pencil, Pen, or Marker tool from the left rail. Draw notes, circle critical pathways, or highlight text. Use the bottom color palette to pick vibrant colors and stroke thicknesses. Made a mistake? Switch to the Eraser to tap and remove strokes instantaneously.

5

One-Click Export to PPTX, PDF, SVG or ZIP

Click the Export button in the top right. Select PowerPoint (.pptx) to generate native editable shapes and connectors, PDF for a multi-page book, SVG for lossless vector embedding, or ZIP for full lesson JSON backups.

Pro-Tip: Instant Image Paste from Clipboard

You can paste images (PNG, JPG, WebP) or animated GIFs directly onto the canvas by pressing Ctrl+V. Lumenboard automatically embeds the asset in your project database with offline persistence!

Workspace Anatomy

Understand each region of the Lumenboard interface

UI Layout
1. Top Bar

Navigation & Global Actions

Contains the brand mark, project status, File Menu (Import PDF/DOCX/JSON/Assets), Dark/Light mode toggle, Fullscreen toggle, and the primary Export action button.

2. Left Rail

Creation & Annotation Tools

Quick access to Select (V), Pan (H), Pencil, Pen, Marker, Eraser (E), Rich Text (T), Design Library, AI Code Visualizer, and AI Text Visualizer.

3. Infinite Canvas

Expandable White Working Area

The high-resolution drawing surface. Use the bottom controls to expand canvas width/height (hold to grow continuously), zoom smoothly (Ctrl+Wheel), or fit canvas bounds directly to your diagram content.

4. Inspector Panel

Contextual Properties & Styling

Opens automatically when items are selected. Fine-tune card dimensions, fill colors, opacity, rotation angle (0° - 360°), layer depth (Bring Forward/Send Backward), and arrow styles.

Multi-Page Lesson Notebooks

Manage chapters, slides, and modular lessons inside a single project

Notebooks

🎨 Color-Coded Lesson Tabs

Right-click or click the menu button on any lesson tab to assign unique color tones (Indigo, Mint, Coral, Sun, or custom hex). Helps visually organize multi-module courses or sprints.

🔍 Tokenized Page Search

Instantly locate any slide in 100+ page documents using the top search bar. Searches whole word tokens and preserves matched lesson ordering.

🗂️ Drag & Drop Reordering

Drag lesson tabs horizontally in the top strip to change lesson order. The new order is automatically reflected in PDF and PowerPoint exports.

📦 Batch Selection & Operations

Hold Shift while clicking lesson tabs to select a continuous range. Batch delete pages or export selected subsets to ZIP / PDF.

Live JSON Schema & Recovery

Every lesson is serialized as clean JSON. You can open the JSON Editor from any lesson menu to inspect, copy, or paste diagram structures programmatically.

Smart Connectors & Line Crossing Bridges

Intelligent arrows that snap, route around obstacles, and automatically create visual bridge bumps

Flow & Routing
Interactive Visual Flow Simulation Connector Routing & Bridge Overpasses

🔀 4 Connector Styles

Switch effortlessly between Elbow (orthogonal layout), Curved (smooth cubic Bézier), Straight, and Dashed lines with start/end arrowheads.

🌉 Automatic Line Crossing Bridges

When two lines cross in complex flowcharts, Lumenboard dynamically computes the exact intersection and renders a smooth 3D-like overpass bridge so readers never confuse intersecting signals.

🧲 Smart Anchor Snapping

Connectors magnetically lock to the 4 cardinal edges of any card, frame, decision diamond, or sticky note. Moving the card moves connected lines automatically.

📍 Interactive Bend Handle

Click any connector to reveal its midpoint bend handle. Drag it anywhere to shape customized routing paths around obstacles.

Shapes, Container Frames & Asset Library

Create clear component hierarchies with bounding containers and rich shapes

Shapes & Library

🖼️ Container Frames

Frames act as visual clusters (e.g. "Frontend Tier", "AWS Cloud VPC"). Dropping cards inside a frame automatically groups them—moving the parent frame moves all child cards together.

🔷 Shapes & Decision Diamonds

Includes Rectangles, Squares, Circles, Pills, and Decision Diamonds (with True/False branching anchors) for standard UML and flowchart modeling.

🔄 Free Angle Rotation

Rotate any block or text box with the rotation handle. Hold Shift while dragging to snap precisely to 15-degree increments (0°, 15°, 30°, 45°, 90°, etc.).

📚 Design Library

Pre-built multi-step templates: "How Webpages Become Interactive", "Process Flows", "HTML/CSS/JS Architecture", and system topologies ready to drop onto the board.
