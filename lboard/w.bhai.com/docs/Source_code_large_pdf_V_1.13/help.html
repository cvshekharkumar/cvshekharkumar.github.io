Smart Connectors & Proprietary Jump-Bridge Overpasses

Eliminate line-crossing clutter with automatic arched overpasses and orthogonal routing.

In complex architecture diagrams, overlapping wires create visual confusion. Lumenboard solves this with an automatic Jump-Bridge / Bump Overpass algorithm.

↳

Orthogonal Elbow Routing

Automatically calculates clean 90-degree right-angle paths around cards to maintain neat, professional electrical/software schematics.

⌒

Automatic Jump-Bridges

Whenever two connector lines cross, Lumenboard detects the intersection and renders an arched bridge on the upper wire, indicating clearly that the lines do not merge.

∿

Media Engine: Video Transcoding, GIF Optimizer & Crop Editor

Embed, convert, crop, and compress multimedia assets directly inside the browser.

🎥

WebAssembly FFmpeg Video Transcoder

Import legacy video formats (.avi, .3gp, .mp4) via File → Import Video File. Lumenboard leverages an in-browser WebAssembly FFmpeg worker to transcode videos into lightweight, browser-native WebM videos without sending any data to a remote server.

Smart GIF Optimizer (30–80 KB Target)

Import animated GIFs from your computer. Lumenboard includes an intelligent multi-pass quantization engine that compresses large GIFs into ultra-compact 30–80 KB payloads while preserving fluid animation framerates.

Right-click any image or click Crop image in the Inspector panel. Drag the interactive corner handles to crop graphics directly on the canvas without needing external image editors.

Frequently Asked Questions & Pro Tips

Everything you need to know about performance, storage, and troubleshooting.

Where is my data stored? Is my data private? ▼
100% Private & Local: Lumenboard operates entirely on your device. All your diagrams, lesson slides, imported PDFs, drawings, and media assets are stored directly in your browser's IndexedDB (lumenboard_media_db) and LocalStorage. No diagrams or files are ever transmitted to an external server.
How do I clear browser storage or reset the application? ▼
Open the File Menu in the top bar and click Remove browser saved data (⌫). This will safely purge the LocalStorage keys and delete the IndexedDB database to restore the studio to its pristine factory state.
What should I do if a large 100+ page PDF import takes time? ▼
Lumenboard renders PDF pages using asynchronous streaming directly via pdfjs-dist. A progress bar will show the exact page count being rendered. For optimal performance on massive 200+ page documents, you can use the Delete Pages tab to remove unneeded pages or export as a packaged ZIP archive.
How does the PowerPoint (.pptx) export work? ▼
Unlike basic tools that merely take flat screenshot images, Lumenboard's exporter translates each rectangle, circle, decision node, text block, and connector into native Microsoft PowerPoint XML shapes using pptxgenjs. When you open the exported file in PowerPoint or Google Slides, every shape and text box remains fully editable!
