2-Minute Quick Start Guide

Get up and running with your first professional diagram or multi-lesson presentation in four simple steps.

1

Create or Choose a Lesson Page

When Lumenboard launches, you start on Lesson 1. You can click ＋ on the bottom bar to add more pages, double-click any tab to rename it, or pick from ready-to-use frameworks under the Templates tab on the left panel.

2

Add Shapes, Freehand Ink or Code Visualizations

Click shapes on the left Design Library (Rectangles, Squares, Circles, Diamonds, Decision nodes, or Start/End Pills). Alternatively, pick the Pen ✒ or Pencil ✎ tools to draw freely with your mouse or stylus tablet, or click Visualize code </> to generate architecture trees instantly.

3

Connect Objects with Smart Routing

Hover over any shape edge to reveal the purple ＋ connection handle. Hold Shift and drag toward another shape. Lumenboard will automatically calculate clean orthogonal routing and render arched bridge bumps where lines intersect!

4

Export & Share in Any Format

Click the Export ↗ button on the top right to download your work as a multi-page Lesson-by-Lesson PDF, presentation-grade SVG, high-resolution PNG, Project JSON, or Lesson ZIP.

💡 PRACTICAL GUIDES

Step-by-Step Practical Tutorials

Learn how to tackle common diagramming challenges with ease.

Tutorial 1: Creating a Cloud Microservices Architecture Diagram ▼
  1. Open the Design panel on the left and select Frame (⌗). Place a frame and title it "Cloud Infrastructure".
  2. Add rectangles for your Microservices: Auth Service, Billing Service, and Orders Service. Set their tone to Mint or Indigo.
  3. From the Desktop Icons section, drag Database, Cloud, and Server icons onto your cards.
  4. Hold Shift over the edge of the Auth Service, drag to the Database, and pick Elbow (↳) or Dashed (⇢).
  5. Select the connector in the Inspector, choose your preferred arrow color, and adjust line thickness.
  6. Click Export ↗ and choose Scalable SVG or High-Res PNG.
Tutorial 2: Producing a Multi-Page Courseware Deck with PDF Export ▼
  1. On the bottom bar, click ＋ to add 5 lesson tabs: Lesson 1: Intro, Lesson 2: Core Concepts, etc.
  2. Right-click each tab to assign distinct tab colors for easy navigation.
  3. Populate each lesson canvas with diagrams, notes, and tables.
  4. Click Export ↗ → Lesson-by-Lesson PDF. Lumenboard will render each lesson sequentially and download a single multi-page PDF document!
Tutorial 3: Visualizing Complex Codebases in 1 Click ▼
  1. Click Visualize code </> on the top menu.
  2. Paste your backend controller, API handler, or algorithm code into the editor.
  3. Select HLD (High level) for an architectural overview, or LLD (Low level) for step-by-step logic nodes.
  4. Click Generate diagram →. Lumenboard will instantly lay out cards, code snippets, and linked connectors inside a dedicated frame.
❓ HELP CENTER

Frequently Asked Questions

Find answers to common questions about storage, formats, and performance.

Where is my data stored? Is my code or diagram sent to a server? ▼

Lumenboard is 100% client-first. All diagrams, media assets, and code inputs are stored locally in your browser's IndexedDB and localStorage. Nothing is sent to any external server without your explicit action.

How do I crop or replace an image I added? ▼

Right-click any image on the canvas and select ✂ Crop image to open the interactive visual cropper. You can also copy (Ctrl+C) or cut (Ctrl+X) images directly from the right-click menu.

How many undo steps are supported? ▼

Lumenboard maintains a deep history stack of up to 250 undo/redo operations (Ctrl+Z and Ctrl+Y), allowing you to explore and experiment fearlessly.

Can I import a ZIP file with hundreds of lessons? ▼

Yes! Use File → Import JSON or ZIP to replace your project with a complete lesson pack, or File → Append ZIP to merge new lessons into your existing deck without overwriting previous work.
