Chapter 1

⚡ 60-Second Quickstart Guide

Create your first polished diagram or multi-page visual lesson in under a minute with these four easy steps.

1

Choose a Template or Start Blank

Click Templates in the top bar to open pre-built structures like Web Foundations, Architecture Overview, or Flowcharts. Or pick Card / Concept (□) from the left rail to drop your first box anywhere on the canvas.

2

Connect Nodes & Annotate

Hover near any node edge while holding Shift (or click the + handle) and drag to another shape to create an auto-routing connector arrow. Switch to Pen (✒) or Marker Highlighter (▰) to annotate directly on the board.

3

Customize Style via Inspector

Click any object to open the right-hand Properties Panel. Adjust colors, opacity, line thickness, rotation degrees, icon badges, rich formatted text, or crop imported images.

4

Present & Export

Press Ctrl + F for distraction-free Fullscreen presentation mode. When ready, click Export to download a standalone Interactive Lesson HTML, a complete Website ZIP, crisp SVG / PNG, or a multi-page PDF.

↗ Smart Connectors & Dynamic Routing

→

6 Distinct Arrow Styles

  • Straight Line (―): Clean structural links.
  • Straight Arrow (→): Unidirectional data flow.
  • Both-Sides Arrow (↔): Bidirectional synchronization.
  • Elbow / Orthogonal (↳): 90-degree circuit & architecture paths.
  • Curved Bezier (∿): Organic, fluid flowcharts.
  • Dashed Connector (⇢): Async or optional relations.
⚡

❓ Troubleshooting & Frequently Asked Questions

Quick solutions to common questions and performance optimization tips.

Where is my diagram data stored? Is my code or data uploaded to a server? +
100% of your data stays private on your machine. Lumenboard operates entirely in your browser using local memory, IndexedDB, and LocalStorage. No diagrams, code snippets, imported PDFs, or videos are ever uploaded to any cloud backend or external server.
How do I save my project permanently? +
Press Ctrl + S to immediately save the project to your browser's persistent storage. For permanent backups and cross-device transfers, click Export → Project JSON or Lesson ZIP to save the files to your computer.
How do I clear the browser cache if storage gets full? +
Open the top File menu and select Remove browser saved data (⌫). This safely clears LocalStorage and IndexedDB media cache after asking for your confirmation.
Why is my stylus triggering right-click menus while drawing? +
Lumenboard automatically suppresses the context menu when in Pencil, Pen, Marker, or Eraser mode. Ensure you have selected a drawing tool from the left rail (✎, ✒, or ▰) before using your stylus.
How can I import a massive 1,000-page PDF textbook smoothly? +
Click File → Import PDF as lessons and select your file (up to 3 GB). Lumenboard uses streaming chunk loaders so only the active page is rendered in memory, keeping your browser fast and responsive.
