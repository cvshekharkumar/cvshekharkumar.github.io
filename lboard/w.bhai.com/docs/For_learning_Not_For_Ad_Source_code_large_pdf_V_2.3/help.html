Chapter 01

0 to 60s Quick Start

Get productive in seconds with the three core steps of the Lumenboard creation workflow:

1

Select a Starting Point or Template

Click Templates in the top menu or choose a quick start from the left library: Process flow, DOM tree, System map, or Lesson canvas. Alternatively, drop a PDF or DOCX file directly onto the canvas to instantly create full lesson pages.

2

Build & Connect Concept Nodes

Click □ for Concepts, ◇ for Decisions, or T for Rich Text. Hold Shift or hover over edge connection points to draw magnetic arrows with automatic jump-over bumps and orthogonal routing.

3

Export & Share Anywhere

Click the Export ↗ button in the top right to download standalone interactive HTML, a complete multi-page Website ZIP, editable PowerPoint (.pptx) slides, high-resolution PNG, or scalable vector SVG.

💡
Instant Save & Offline Storage: Press Ctrl + S anytime to persist your entire workspace to browser IndexedDB storage. Your diagram and uploaded media remain completely private and available offline!

Chapter 05

Smart Connectors & Routing

Lumenboard provides algorithmic line routing and intersection arc jumps to ensure clean architecture diagrams.

↗
4 Connector Path Styles
  • Straight: Direct point-to-point geometric vector.
  • Elbow (Orthogonal): 90-degree step routes ideal for circuit maps and software flowcharts.
  • Curved: Organic cubic bezier curves for mind maps.
  • Dashed: Broken stroke styling for asynchronous dependencies.
⌒
Automatic Jump-Over Bumps
When two connector lines intersect, Lumenboard automatically creates an elegant half-circle bridge (bump) on the intersecting segment. This prevents ambiguous 4-way crossings!
⚡

Quick Connect Feature

Hold the Shift key and hover over any shape perimeter to reveal 8 magnetic snap handles (top, bottom, left, right, and corners). Click and drag from any handle to immediately connect to a target node.

Import legacy AVI, 3GP, or MP4 files. An embedded FFmpeg WebAssembly engine automatically converts them locally into lightweight, ultra-smooth WebM video playback cards without sending bytes to external servers!

Import animated GIFs for UI demos and animations. The integrated compression engine optimizes GIF frame size and maintains smooth 60fps playback on the canvas.

Chapter 08

AI & Automation: Code & Text to Diagram

Instantly generate structured visual flowcharts from raw source code or unstructured text.

Click Visualize code in the top menu or the </> button on the rail. Paste code in JavaScript, TypeScript, Python, C++, or Go, and select one of 3 detail levels:

1. Basic (High-level)
Extracts primary function entry points, major conditional branches, and core output return values.
2. Intermediate
Includes intermediate variable state mutations, helper function calls, and error handling paths.
3. Advanced (Deep Architecture)
Maps out complete asynchronous loops, internal promise chains, try/catch blocks, and edge cases.
