⚡ Quick Start

Get Up and Running in 60 Seconds

Follow this proven 4-step workflow to produce your first high-impact visual diagram.

1

Choose Your Canvas or Template

Open the Templates tab in the left sidebar to start with ready-made architectures: Process Flow, DOM Tree, System Map, or Lesson Canvas. Alternatively, double-click anywhere on the blank canvas to drop your first card.

2

Add Smart Shapes & Sticky Notes

Select shapes from the left rail (Rectangles, Circles, Diamonds, Decisions, Start/End Pills, Callout Sticky Notes). Double-click any element to edit its title, detail text, or rich-text format.

3

Connect with Magnetic Smart Arrows

Hover over any shape's border until the blue connector dot appears, then drag to another shape. Lumenboard will automatically snap the line and route around obstacles using intelligent elbow or smooth curved Bézier paths.

4

Export or Present in Fullscreen

Click the Export button to download as high-res PNG, SVG vector, PDF document, or multi-slide PowerPoint presentation (.pptx). Press F11 to enter full presentation mode.

🧭 Workspace Anatomy

The Lumenboard Studio Layout

An intuitive 5-zone workspace built for maximum visual real estate and rapid interaction.

1. Top App Bar

Houses the Lesson Title, File Menu (Import DOCX, Images, GIFs, ZIP packages), Templates trigger, Code / Text Visualizers, Zoom controls (35% – 200%), Theme switcher, and the Export hub.

2. Left Tool Rail

Quick-action vertical toolbox containing: Pointer Selection tool, Pan Canvas tool, Rich Text Block, Pencil, Pen, Marker Highlighter, Eraser, Add Connector, Add Sticky Note, and Add Frame.

3. Design & Templates Library

Collapsible side-panel with search filter. Provides instant access to Basic Shapes (Rectangle, Circle, Diamond, Decision, Pill), Arrow Styles, and Starter Templates.

4. Right Inspector & Properties Panel

Appears when selecting any element. Allows precise adjustment of Colors, Tones (Indigo, Mint, Coral, Sun), Fill Opacity, Rotation, Stroke Width, Z-Layer ordering, Icon assignment, and Code Snippets.

💡
Pro-Tip on Panel Toggles: Press the toggle button < or > beside the left rail to collapse the Library panel for an expansive ultra-wide drafting canvas!

↗️ Connectors & Routing

Intelligent Magnetic Connectors

Never struggle with messy crossing lines again. Lumenboard features automated obstacle-avoiding routing.

Smart Orthogonal Elbow Routing

Calculates optimal 90-degree step paths between nodes, dynamically routing around obstacles on your canvas. Drag the mid-waypoint handles to manually reshape bends whenever needed.

Direct Straight & Dashed Lines

Direct point-to-point connections with optional dashed styling. Great for async message queues, dependency linkages, or relationship mapping.

💻 Code Visualizer

Code-to-Diagram Tree Engine

Visualizes DOM trees, HTML page layouts, and React/JSX component hierarchies effortlessly.

How to Use Code-to-Diagram

1. Click Visualize code (or the </> button on the left rail).
2. Select detail granularity (High vs Low).
3. Paste your HTML or JSX code and click Visualize Code. Lumenboard parses the nested AST structure into connected visual node cards.

❓ Support & FAQs

Frequently Asked Questions

Quick answers to common questions about saving, security, and performance.

Where is my diagram data stored? ▼
All diagrams, strokes, lessons, and assets are stored 100% locally in your browser's persistent LocalStorage database. No diagram content is sent to third-party tracking servers. You can export complete project backups as JSON or ZIP at any time.
Can I use a digital stylus or drawing tablet? ▼
Yes! Lumenboard includes high-precision pointer event listeners compatible with Apple Pencil, Wacom tablets, Microsoft Surface Pens, and touchscreens.
How do I export all lessons into a single presentation? ▼
Open the Export modal from the top navigation bar and select Export PowerPoint (.pptx). Each lesson board in your project will be automatically generated as an individual high-definition slide.
How do I reset or recover from an accidental deletion? ▼
Lumenboard keeps an extensive history stack of up to 250 actions. Simply press Ctrl+Z repeatedly to rewind your canvas to any prior state.
