5-Minute Quick Start Guide

Get up and running with your first professional diagram in five simple steps.
1

Choose a Starting Canvas or Template

When you launch Lumenboard Designer, click on Templates in the left drawer or top navigation bar. Pick from Process Flow, DOM Tree, System Map, or start with a clean infinite canvas.

💡 Pro Tip: You can create multiple independent canvas tabs (e.g., Lesson 1, Lesson 2) using the ＋ tab button at the bottom left.
2

Drop Shapes, Cards & Sticky Notes

Click any basic shape in the left Design Library (Rectangles, Squares, Circles, Diamonds, Decisions, Pills, or Sticky Notes). Double-click any element on the canvas to rename its title, subtitle, and short desktop icon label.

3

Connect Nodes with Smart Orthogonal Arrows

Hover near the edge of any box until the circular ＋ connector handle appears. Hold Shift and drag a line to another box. Lumenboard automatically calculates obstacle-avoiding orthogonal paths, elbows, or curved lines!

4

Add Freehand Sketches, Rich Text & Tables

Switch between the Pen, Pencil, Marker Highlighter, or Eraser tools on the left rail to write hand-drawn notes. Select the T text tool to insert rich formatted text boxes with bold, bullet lists, color highlights, and interactive multi-cell tables.

5

Export in Your Format of Choice

Click the top-right Export ↗ button. Choose Editable PowerPoint (.pptx) to generate real PowerPoint slides where every card and arrow is a native vector shape, or export to crisp SVG, 2x PNG, PDF, or Project JSON.

Workspace Anatomy & Layout

Understand every toolbar, drawer, and property inspector panel in the studio.
Top

1. Top Application Bar

Provides project status indicator ("Saved locally"), File menu (JSON, Image, Icon, GIF import), Templates, Code & Text Visualizers, Fullscreen mode (Ctrl+F), Dark/Light theme toggle, and the Export Center.

Rail

2. Left Creation Rail

Houses primary mode tools: Pointer (↖), Pan/Hand (✥), Pencil (✎), Pen (✒), Marker Highlighter (▰), Eraser (◇), Quick Add Concept, Decision, Formatted Text (T), Sticky Note, and Lesson Frame (⌗).

Lib

3. Library & Template Drawer

Collapsible drawer offering searchable basic shapes, arrow styles, pre-configured learning blocks, 8+ desktop computing icons (Web, PC, DB, API, Code, Doc, User, Settings), and curated diagram starter templates.

Canvas

4. Interactive Canvas

The high-performance working area. Supports infinite pan, smooth mouse-wheel zooming (Ctrl+Scroll), multi-selection bounding marquee, rotation grips, edge connection anchors, and real-time freehand stroke rendering.

Prop

5. Properties Inspector

Right-side inspector showing properties for whatever is selected: Arrow styles, stroke thickness, color palettes, opacity sliders, fill modes (opaque/transparent), exact geometry (X/Y/W/H), rotation angle, and layer reordering.

Foot

6. Footer & Lesson Bar

Manages multi-lesson slide tabs (rename, color-tag, duplicate, delete), canvas working area dimensions (e.g., 2400 × 1600), fit-to-diagram, and zoom percentage controls (35% to 200%).

Rich Text, Typography & Interactive Tables

Embed rich formatted documentation, bullet lists, custom fonts, and multi-cell data tables directly into your canvas.

WYSIWYG Rich Text Toolbar

Click the T tool on the left rail, then click anywhere on the canvas to place a formatted text box. When selected, a full formatting toolbar appears:

  • Fonts & Sizes: Arial, Georgia, Verdana, Tahoma, Courier New (Sizes 10pt to 48pt).
  • Styling: Bold (Ctrl+B), Italic (Ctrl+I), Underline (Ctrl+U), and Strikethrough.
  • Colors: Custom text color picker and background highlight marker.
  • Lists & Indents: Bullet points, Numbered lists, Indent (Tab) and Outdent.
  • Alignment: Align Left, Center, Right, or Justify.

Interactive Table Grid Generator

Click the ▦ Table button in the text toolbar to reveal the interactive grid selector. Hover to choose up to 8 columns × 8 rows (64 cells). Tables feature built-in styled header rows, custom borders, and word wrapping.

How to Connect Any Two Shapes in 2 Seconds

1. Move your cursor to the border edge of your source card.
2. Hold Shift to reveal the blue ＋ connection handle.
3. Click and drag the arrow directly onto your target card.
4. Release the mouse and pick your preferred style from the quick popup menu!

Automated Code Visualizer (HLD & LLD)

Instantly convert HTML, CSS, JavaScript, and module code into fully connected visual architecture diagrams.

High-Level Design (HLD)

Analyzes your code's foundational tiers (Source, HTML DOM Structure, CSS Styling, JavaScript Logic, Browser Output) and generates a macro-level architecture flowchart.

Frequently Asked Questions & Troubleshooting

Quick solutions to common questions and edge cases.
Where is my diagram data saved? ▼
All diagram items, lesson tabs, canvas dimensions, and formatting are saved automatically into your browser's local storage (localStorage) in real-time. To back up your work permanently or transfer it to another computer, export the Project JSON via the Export Center.
Can I edit exported PowerPoint files in Microsoft PowerPoint or Keynote? ▼
Yes! Lumenboard uses standard Office Open XML geometries. Every card is an authentic PowerPoint shape, every connector is an editable PowerPoint vector connector, and all text runs retain their original formatting and font sizes.
How do I delete or reorder connection bend points? ▼
Click on the connector line to select it. Interactive circular bend handles (●) will appear. Drag them to reshape the arrow. To return to the automatically calculated obstacle-avoiding route, click Reset automatic route in the right-hand Properties Inspector.
Can I use Lumenboard offline without an internet connection? ▼
Yes! Lumenboard Designer is a self-contained progressive web studio with no external runtime dependencies. All visualizer parsing, drawing calculations, rasterizations, and PowerPoint generators execute locally on your machine.
