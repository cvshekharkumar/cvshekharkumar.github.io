✎

Renaming & Duplicating Lessons

Right-click any lesson tab or click its three-dot menu to Rename (e.g., "Lesson 1: Introduction", "Lesson 2: System Flow") or Duplicate to branch off variations.

{ }

Shapes, Fills, Rotations & Layer Ordering

Build structured conceptual models with geometric precision. Every shape supports solid or transparent fills, precise resizing, rotation, and dynamic layer ordering.

🔲

Shape Variants

Rectangle / Square: Classic process blocks.
Circle / Oval: Terminals and state nodes.
Diamond: Decision and branching points.
Pill / Capsule: Start/End triggers.
Frame: Container grouping related cards.

🎨

Curated Color Tones

Choose from harmonic preset tones: Indigo (structure), Mint (success/start), Coral (alerts/decisions), Sun (notes/warnings), or open the custom RGB color wheel for infinite palette freedom.

⭕

Solid vs. Transparent Outline

In the Inspector's Shape Fill toggle, choose between solid filled backgrounds or clean transparent outline mode. Great for grouping boxes inside frames without obscuring backgrounds.

Rotate any shape clockwise or counter-clockwise in clean 15° increments with quick buttons, or enter exact degree angles from -180° to +180° in the numeric field.

Coordinate-Aware Layer Ordering ("Place Above / Place Below")

Instead of confusing global z-index numbers, LumenBoard detects which shapes physically overlap at the current coordinate. Simply select an overlapping object and click Place Above or Place Below.

Ready-to-Use AI Prompt for ChatGPT / Claude / Gemini

Copy this prompt and paste it into any LLM along with your topic. It will generate a valid JSON array ready to paste into LumenBoard's { } Lesson JSON editor: 

Generate a valid JSON array for Lumenboard Visual Studio representing a flowchart for: [INSERT YOUR TOPIC HERE].

JSON Format Rules:
- Return ONLY the JSON array without markdown formatting.
- Each object must have:
  - id: unique string (e.g. "step-1", "step-2", "conn-1")
  - type: "card" | "decision" | "frame" | "connector" | "text"
  - x: number (canvas X coordinate, between 100 and 2000)
  - y: number (canvas Y coordinate, between 100 and 1200)
  - w: number (width, min 160)
  - h: number (height, min 100)
  - title: string
  - detail: string (description)
  - tone: "indigo" | "mint" | "coral" | "sun"
  - shape: "rectangle" | "square" | "circle" | "pill" | "diamond"
- For connectors:
  - type: "connector"
  - arrowStyle: "straight" | "elbow" | "curved" | "dashed"
  - showArrowhead: true
  - strokeColor: "#6c5ce7"
  - sourceId: id of starting card
  - targetId: id of ending card

💡 Chapter 12

Pro Tips, Performance & FAQ

Answers to common questions and tips to get the most out of LumenBoard Visual Studio.

Does LumenBoard work offline?

Yes! LumenBoard runs completely in your browser. All code visualizers, text visualizers, PDF parsers, and PowerPoint generators execute locally with 100% data privacy.

How large can the canvas get?

The canvas supports dimensions up to 8000 × 6000 pixels. Use the dual top & bottom scrollbars and zoom presets (50% to 200%) to navigate expansive architectures.

Can I edit imported PDF text?

Imported PDF pages are rendered as high-fidelity crisp vector-raster layers. You can draw on top of them, highlight with markers, add floating text cards, crop sections, and re-export.

How do I share my project with a teammate?

Click Export > Export Lesson ZIP or Export > JSON. Your teammate can click File > Import from computer and instantly load your full deck!
