GETTING STARTED

5-Minute Quick Start Guide

Follow these core steps to build and present your first visual diagram in minutes.

1

Add Shapes, Cards & Decision Diamonds

From the left Tool Rail or the Design Library, click any shape (Rectangle, Square, Circle, Diamond, Pill, Callout, or Frame Container) to place it on the canvas. Double-click any shape to immediately edit its title and details.

□ Concept ◇ Decision ⌗ Frame Container Double-Click to Edit
💡 Pro Tip:

Frames act as magnetic containers! Moving a frame will automatically transport all shapes and connectors placed inside it.

2

Connect Objects with Smart Arrows

Hold Shift and hover near the edge of any shape to reveal the glowing (+) Connector Handle. Drag the handle to any target shape to instantly spawn a smart connecting line. Choose between straight, orthogonal elbow, curved, or dashed styles.

Hold Shift + Drag Smart Auto-Routing Bridge Line Hops Reset Route
⚡ Obstacle Avoidance:

Lumenboard's A* routing engine automatically maneuvers arrows around intervening cards so lines never collide or tangle.

3

Write Formatted Rich Text & Insert Tables

Select the Text Tool (T) and click on the canvas to place a rich text block. Use the floating formatting bar for Bold, Italic, colors, bulleted/numbered lists, indentations, and the 8×8 Table Cell Picker.

T Text Tool ▦ Interactive Tables 🖌 Format Painter Auto-Expanding Box
🖌 Format Painter:

Highlight styled text, click the paintbrush icon, and click destination text to clone fonts, sizes, and colors instantly.

4

Freehand Sketching & Highlighting

Switch between the Pencil (semi-opaque sketch), Pen (crisp vector ink), Marker (28% highlighter blend), and Eraser (vector stroke eraser). Smooth curves are calculated in real time without lag.

✎ Pencil ✒ Pen ▰ Marker Highlighter ◇ Stroke Eraser
🎨 Color & Size Control:

Adjust brush thickness from 1px to 100px and choose custom hex colors directly from the active tool toolbar.

5

Export to Native PowerPoint, PDF, SVG & ZIP

Click the Export ↗ button in the top right to download your work in presentation-grade formats: true editable Microsoft PowerPoint slides (.pptx), multi-lesson PDFs, 2x supersampled PNGs, SVGs, or timestamped Lesson ZIP archives.

Editable .PPTX Multi-Page PDF High-Res PNG Lesson ZIP
📊 Native PPTX Shapes:

Exported PowerPoint slides contain native vector shapes and editable text, allowing full post-export editing in Microsoft Office!

Code & Text Auto-Visualizer

Transform raw source code snippets or unstructured textual explanations into fully connected architectural diagrams automatically.

  • ✓
    Code Visualizer (</>): Parses HTML, CSS, JavaScript, or general code structures into High-Level (HLD) or Low-Level (LLD) relationship trees.
  • ✓
    Text Visualizer (TXT): Extracts key concepts, definitions, and sequential stages from paragraphs or bullet lists into linked learning cards.
  • ✓
    100% Client-Side Privacy: Your code and text stay entirely within your browser and are never transmitted to external servers.
  • ✓
    Fully Editable Output: All generated boxes, titles, syntax code panels, and connectors remain fully editable and movable.

High Level (HLD) vs Low Level (LLD)

HLD (High Level Architecture):
Creates a horizontal end-to-end pipeline (e.g. Source Code → DOM → CSS → Event Loop → UI Output).
LLD (Low Level Detailed Flow):
Creates hierarchical parent-child trees with embedded syntax snippets, event listeners, and function blocks.
