Summary of Software Upgrades: What Customers Need to Know Before Purchasing

Every major release in this suite addresses specific workloads. Reviewing these distinctions ensures clients purchase the exact build matched to their hardware and use case:

  • V0.4 - V0.7 (Foundation Edition): Ideal for lightweight diagramming, basic whiteboard drawing, 8x8 table inserts, and basic flowcharting. (Starting at ~28ms latency).

Version Upgrade Evolution & Engineering Milestones

Deep dive into the generational leaps across the software history:

Milestone 4: Ad-Free Pro Educational & Enterprise Series (V2.0 - V2.3)

Flagship Ad-Free Suite

Why Upgrade to V2.x? Built specifically for institutions, schools, and professional trainers who require a distraction-free, 100% offline standalone whiteboard environment without third-party tracking or ad bloat.

V2.0 Release:

Complete purge of telemetry, analytics, and advertising scripts. Pure offline standalone operation.

V2.1 Release:

Added classroom recording toolkit, student workbook packaging, and teacher watermark control.

V2.2 Release:

Interactive Flat Panel Display (IFPD) 4K touch optimization, dual-pen color recognition, and palm rejection.

V2.3 Flagship:

Ultra-low <8ms latency spline engine, AI diagram auto-alignment, multi-layer drawing sheets, and automatic history rollback.

Milestone 3: High-Capacity Large PDF Edition Series (V1.0 - V1.13)

14 Incremental Builds

Why Upgrade to V1.x? Early whiteboard versions struggled with heavy PDF files. The V1.x series engineered a dedicated WebAssembly & Web Worker PDF rendering engine that loads 500+ page books seamlessly without browser crashes or memory exhaustion.

V1.0 - V1.3:

Introduced multi-page canvas PDF viewer, split-screen viewing, and vector zooming without pixelation.

V1.4 - V1.6:

Added in-document PDF full-text search, multi-color highlighters, sticky annotations, and Catmull-Rom stylus curves.

V1.7 - V1.9:

Added KaTeX LaTeX math formula engine, PPTX slide export with embedded vectors, presenter view, and speaker notes.

V1.10 - V1.13:

Extreme memory compression for 500+ MB PDFs, background tile caching, instant screenshot crop, and flattened PDF export.

Milestone 2: Lumenboard Designer Studio Series (V0.1 - V0.3)

Specialized Architecture Tool

Why Choose Designer Studio? Built for system engineers, software architects, and UI/UX designers who need precision pixel alignment, cloud service icon libraries (AWS, Azure, GCP, Kubernetes), and interactive clickable prototyping.

Designer V0.1:

Isometric grid canvas, UI component wireframing stencils, and BPMN/UML orthogonal routing.

Designer V0.2:

Comprehensive Cloud Architecture icon library (AWS, Azure, GCP, Cisco), nested frames, and auto-layout flex alignment.

Designer V0.3:

Clickable prototype link connectors, layer hierarchy tree panel, SVG vector path editor, and CSS generation.

Milestone 1: Core Foundation Series (V0.4 - V0.7)

Baseline Whiteboard

The Original Whiteboard Genesis: Established the fundamental vector canvas, smart physics connectors, 8x8 table inserter, Code Visualizer (HLD/LLD modes), and basic PPTX/SVG/PNG export hub.
