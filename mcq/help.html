Quick Start in 3 Easy Steps

Get up and running as a Teacher or a Candidate in minutes

👩‍🏫 For Teachers / Examiners:

1

Create Questions & Options

Use + Question to write rich HTML problem statements, define Single/Multiple MCQ options, and pick the correct answer key.

2

Configure Timer & Locks

Set exam duration (minutes), lock the timer, and lock questions/options/clear key with a teacher passcode.

3

Export Set ZIP or JSON

Click Export Set ZIP for password-protected student testing, or Export JSON for full backup and editing.

🧑‍🎓 For Students / Candidates:

1

Import Assessment ZIP

Click Import ZIP, select the teacher's exam package, and enter the assessment password.

2

Verify & Start

Enter Name, Roll Number, allow Camera snapshots and Screen sharing, then click Ready to Exam.

3

Answer & Submit

Navigate through questions, select answers, and click Finish Assessment to generate the verified submission report.

💡
Instant Mock Testing: On the welcome screen, click 🚀 Try with mock test data to instantly import a complete 7-question Python MCQ assessment set with problem statements, options, and answer keys without needing any files.

Security Locks & Passcode Protection

Prevent students from altering questions, options, or timers

🔒 Problem Statement Lock

Click Enable Editing / Lock Editing to set a teacher passcode (minimum 4 chars). Makes problem text read-only for students.

🔒 Options & Type Lock

Lock question types (single/multiple) and option texts to prevent unauthorized student changes.

🔒 Clear Key Lock

Lock the Correct Answer Clear Key button with a teacher passcode to prevent resetting or modifying correct choices.

🔒 Timer Lock

Locks the duration countdown. Students cannot modify the time or reset the timer without the teacher passcode.

🛡️
Cryptographic Security: Passcodes are hashed with SHA-256 and salt. Passcodes are never stored in plaintext in the exported ZIP packages.

Candidate Exam Workflow

Step-by-step instructions for test takers

  1. Import Assessment ZIP: Click Import ZIP on the action bar and choose the assessment file provided by your teacher.
  2. Enter Package Password: Enter the student assessment password when prompted.
  3. Candidate Verification: Fill out your Full Name and Roll Number. The exam records the exact IST timestamp.
  4. Enable Permissions: Check the consent checkboxes, click Open Camera to enable your webcam preview, and click Share Screen to select your assessment display.
  5. Begin Assessment: Once all prerequisites are verified, click Ready to Exam.
  6. Sequential Forward Navigation: Answer questions one by one. Use Next › to proceed to the next question.
  7. Submit Assessment: Click the red Finish Assessment button when complete to download your verified submission report and evidence bundle.
⚠️
Important Exam Rules: Do not refresh the page unnecessarily, do not close the tab, and do not stop sharing your screen. If you leave or finish early, the assessment session packages the attempt immediately.

Frequently Asked Questions (FAQ)

Troubleshooting and common inquiries

Why does the app recommend Desktop Mode?
Desktop mode ensures sufficient screen space for the split-panel view (Problem Statement on the left and Options/Code on the right) and allows full browser support for camera capture and screen sharing permissions.
What if the camera or screen sharing does not open?
Make sure your browser has permission to access the camera and screen. In Chrome or Edge, check the lock icon next to the address bar and set Camera and Screen sharing to "Allow".
What happens if a student reloads the browser during an exam?
The assessment session stores the absolute deadline in local storage. Reloading the page resumes the existing attempt and does not reset or increase the timer.
How are correct answers scored?
For single-choice questions, the selected option is compared to the correct key. For multiple-choice questions, the student's selected choices must match all configured correct answers. Scores and percentages are computed automatically upon finishing.
How can I test the app immediately with sample mock questions?
Click 🚀 Try with mock test data on the welcome dialog to instantly load a complete 7-question Python MCQ assessment set with code snippets, formatted problems, and validated answer keys.
How do I clear or protect the Correct Answer Key?
Open the Correct Answer tab and click 🗑️ Clear Key to reset your answer key selection for that question. To prevent unwanted clearing, click 🔓 Lock Editing next to Clear Key and create a teacher passcode.
How do I clear saved cookies or reset assessment data?
Click the Clear Cookies button in the top navigation bar to reset local assessment storage and start with a fresh blank question.
