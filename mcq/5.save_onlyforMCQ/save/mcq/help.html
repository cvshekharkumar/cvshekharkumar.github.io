Quick Start in 3 Easy Steps

Get up and running as a Teacher or a Candidate in minutes

💡
Instant Mock Test Exploration: Click 🚀 Try with mock test data on the welcome dialog to immediately load a pre-configured 7-question Python MCQ assessment set with rich problem statements, formatted code blocks, custom choices, and verified answer keys.

👩‍🏫 For Teachers / Examiners:

1

Create Questions & Options

Write rich problem statements with code snippets, images, GIFs, and videos. Choose Single choice or Multiple choice and configure answer options.

2

Configure Timer & Locks

Set duration in minutes. Protect problem statements, answer options, question types, and timer with teacher passcodes.

3

Export Set ZIP or JSON

Click Export Set ZIP, specify a student package password, and distribute the ZIP package to candidates for a secure, proctored test.

🧑‍🎓 For Students / Candidates:

1

Import Assessment ZIP

Click Import ZIP, select your teacher-provided test ZIP, and enter the assessment password provided by your examiner.

2

Verify & Start

Enter your Full Name and Roll Number. Review the proctoring rules, allow camera and screen sharing, and click Ready to Exam.

3

Answer & Submit

Navigate forward through questions, choose your answers, and click Finish Assessment (or let timer auto-submit) to download your verified submission package.

Teacher MCQ Authoring & Question Management

Build rich multi-choice assessments, customize option sets, and manage answer keys

1. Choose Question Type

Select between Single choice (one correct) with radio buttons or Multiple choice (checkboxes) allowing multiple correct options. Lock the dropdown with Lock Editing.

2. Author Options

Click + Add Option to add options (A, B, C, D...). Edit option text directly. Use the trash icon to delete options. Freeze option text with Lock Editing.

3. Define Answer Key

In the Correct answer key tab, mark the correct option(s). Use Clear Key to reset. Lock the clear button with Lock Editing to prevent accidental resets.

4. Exam Owner Setup

Click Exam Setup in the action row to configure your examiner email and post-exam submission window (in minutes) embedded in the package.

🔒
Strict Candidate Key Protection: The Correct Answer Key and answer authoring controls are strictly restricted to teachers. When a student imports a protected assessment ZIP, the entire answer key panel is automatically force-hidden and blocked from the candidate interface.

Security Locks & Passcode Protection

Comprehensive cryptographic application controls for exam integrity

The platform features an advanced modular locking architecture. Every lock uses the browser's Web Crypto API to generate a one-way SHA-256 cryptographic hash of the teacher's passcode (minimum 4 characters). Plaintext passwords are never stored in exports.

Lock Type Target Area Protection Behavior
Upper Header Links Lock Help Guide, Home, App Store Links Prevents candidates from leaving the exam or reading external resources. Clicking prompts for the teacher unlock passcode.
Problem Statement Lock Rich Text Problem Editor Freezes problem text, diagrams, and formatting into read-only view. Blocks editing, pasting, and media removal.
Timer Lock Duration & Set Timer Controls Prevents students from altering exam duration. Enforces countdown start upon assessment entry.
Lock Adding Questions + Question Header Button Prevents students or unauthorized users from inserting additional questions into the assessment set.
Question Type Lock Single / Multiple Choice Selector Freezes the question type selection (Single Choice vs Multiple Choice) across all questions.
Answer Options Lock Option Inputs & + Add Option Freezes option text inputs and disables adding or removing options.
Clear Key Lock Clear Key Button Prevents accidental or unauthorized clearing of the configured correct answer key.
Delete Question Lock Delete Question Button Prevents deletion of questions from the active assessment set.
Protected ZIP Password Complete Assessment ZIP Package Mandatory teacher password created during Export Set ZIP. Students must enter this password to import and open the test.
🛡️
Application-Level Integrity: Locks provide robust application-level control for classroom and institutional testing. When combined with our consent-based camera and screen proctoring, examiners receive a complete, tamper-evident record.

Candidate Verification & Exam Workflow

Step-by-step candidate journey from verification to submission

1

Import & Authenticate

Candidate imports the teacher ZIP package and enters the required assessment access password.

2

Candidate Verification

Candidate fills in Full Name and Roll Number. Date, hour, and minute are automatically stamped from device clock.

3

Hardware & Consent Check

Candidate checks camera & screen consents, opens camera preview, shares full screen, and unlocks Ready to Exam.

4

Start Assessment

The "Ready to start?" confirmation begins the locked countdown timer and initiates real-time proctoring evidence capture.

5

Sequential Answering

Candidate progresses forward question-by-question. Previous navigation is hidden to preserve integrity.

6

Finish & Package Export

Upon clicking Finish (or at timer expiration), the application generates the completed ZIP, PDF report, and result HTML.

🔄
Refresh-Safe Session Resilience: If a student accidentally refreshes or closes the tab during an exam, the absolute expiration deadline and candidate state stored in localStorage resume seamlessly without resetting the countdown timer.

Camera, Screen Proctoring & Anti-Cheat Architecture

Transparent, consent-based evidence collection for human examiner review

📸 Periodic Camera Capture

Captures high-clarity 480x270 PNG camera snapshots once every second. Each frame embeds an indelible timestamp and verification watermark.

🎥 Continuous Screen Recording

Records the candidate's shared exam screen continuously via MediaRecorder and saves it as screen-recording/exam-screen.webm inside the submission ZIP.

🚫 Clipboard & Context Lockout

Copy, Cut, Paste, Drag, and Drop operations are disabled across all problem statement and option elements during the assessment attempt.

⛔ Shortcut & Abort Safeguards

Keyboard shortcuts (Ctrl+C, Ctrl+V, Ctrl+A, Alt tabs) are blocked. Pressing Escape or stopping screen share immediately finishes the attempt and generates the submission package.

⚖️
Ethical Privacy Safeguard: This application explicitly avoids black-box AI algorithms, emotion analysis, eye-gaze tracking, or automated cheating disqualifications. All proctoring evidence is stored locally in the candidate's browser and shared directly with the authorized examiner for human evaluation.

Frequently Asked Questions (FAQ)

Troubleshooting, best practices, and common inquiries

Why does the application recommend Desktop Mode?
Desktop mode provides optimal screen space for the side-by-side problem statement and option authoring panels, and ensures reliable browser permissions for WebRTC camera streaming and full-screen screen recording.
How does the Upper Header Links Lock work?
Examiners can secure the upper navigation icons (Help Guide, Home, App store) so students cannot click away to external websites during exams. Clicking any locked icon prompts for the teacher unlock passcode.
How can I quickly test the app with sample mock questions?
Click 🚀 Try with mock test data on the welcome modal. This instantly loads a comprehensive 7-question Python MCQ assessment set with rich descriptions, code snippets, formatted options, and pre-configured answer keys.
What if the candidate's camera or screen sharing does not open?
Ensure your browser allows camera and screen sharing permissions. In Chrome or Edge, click the tune/lock icon next to the URL address bar and set Camera and Screen sharing to "Allow", then re-click "Open Camera" and "Share Screen".
What happens if a student reloads or closes the tab during an exam?
The assessment session stores the absolute countdown deadline and candidate metadata in localStorage. Reloading the browser immediately resumes the attempt with the exact remaining time without resetting the clock.
How are Single Choice and Multiple Choice questions scored?
For single-choice questions, the candidate's selection is compared directly to the correct answer. For multiple-choice questions, all correct options must be selected. Total score and percentage are computed instantly and recorded in result-report.html.
How do I clear saved cookies or reset the workspace?
Click the Clear Cookies button in the top navigation bar. It removes all stored assessment cookies, local cached questions, and active candidate sessions, returning the application to a clean initial state.
How does Export JSON differ from Export Set ZIP?
Export JSON creates a single unencrypted file containing all questions, rich media data URLs, fonts, and lock hashes for rapid teacher backup. Export Set ZIP creates a password-protected bundle designed for candidates that enforces student verification and hides answer keys.
How can I embed custom fonts into questions?
Click the Font button on the editor toolbar and select your WOFF, WOFF2, TTF, or OTF file. The font is converted into base64, registered via @font-face, added to the Font Family dropdown, and included in exported ZIP/JSON packages.
Can multiple files download automatically upon exam finish?
Browsers may show a prompt saying "This site wants to download multiple files". Ensure you click "Allow" so the completed ZIP, PDF report, result HTML, and instruction files download automatically without interruption.
